ScreenTrail은 윈도우 PC용 무료 화면 캡처 프로그램입니다. 영역 캡처와 스크롤 캡처, 이미지 속 글자 추출, 번역, 화면 녹화와 GIF 저장, 컬러 피커, 배경 제거에 모자이크까지 되는 이미지 편집창을 한 앱에 담았습니다.

기본 정보

ScreenTrail은 정말 무료인가요?

네. 모든 기능을 무료로 사용할 수 있습니다.

어떤 운영체제에서 쓸 수 있나요?

Windows 전용 프로그램입니다. Mac과 Linux는 현재 지원하지 않습니다.

설치와 업데이트

다운로드 버튼을 눌렀는데 브라우저가 파일을 막아요.

새로 배포된 프로그램이라 브라우저가 경고를 띄울 수 있습니다. 다운로드 목록에서 파일 옆 ⋯ 메뉴를 누르고 '유지'를 선택하면 저장됩니다.

설치할 때 “Windows의 PC 보호” 창이 떠요.

코드 서명 인증서가 없는 개인 제작 프로그램에 표시되는 안내입니다. '추가 정보' → '실행'을 누르면 정상적으로 설치됩니다.

회사 PC에도 설치할 수 있나요?

설치 권한이 제한된 PC에서는 보안 정책 때문에 설치가 막힐 수 있습니다. 이 경우 PC 관리자에게 문의해 주세요.

새 버전은 어떻게 받나요?

업데이트가 나오면 이 페이지의 다운로드 버튼이 최신 버전으로 연결됩니다. 새 설치 파일을 받아 실행하면 됩니다. 바뀐 내용은 위 '버전 히스토리'에서 확인할 수 있습니다.

삭제는 어떻게 하나요?

Windows 설정 → 앱 → 설치된 앱에서 ScreenTrail을 찾아 '제거'를 누르면 됩니다.

사용 방법

캡처한 이미지와 영상은 어디서 보나요?

메인 화면의 '최근 샷'에 자동으로 모입니다. 여러 장을 선택해 한 번에 정리할 수도 있습니다.

PC에 있던 이미지나 영상도 불러올 수 있나요?

네. 이미지와 영상 모두 ScreenTrail 창에 끌어다 놓거나, 최근 샷 옆의 '파일 열기'로 불러올 수 있습니다.

단축키가 기억나지 않아요.

메인 화면의 기능 카드마다 단축키가 적혀 있습니다. 이 페이지의 '단축키' 표에서도 한눈에 확인할 수 있습니다.
